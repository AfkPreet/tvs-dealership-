# media/ — raw uploads from the dealership

Drop files here straight from GitHub (**Add file → Upload files** inside each folder).
Any filenames are fine. Nothing in `media/` is published: I review, pick, resize and copy the
chosen files into `public/` myself, so upload freely.

| Folder | What goes in | Notes |
| --- | --- | --- |
| `photos/` | Showroom, bikes on the floor, owner, team, deliveries, workshop | Originals, largest size you have. JPG / PNG / HEIC all fine. |
| `video/` | Showroom walkthroughs, bike clips | MP4 or MOV. **Keep each file under 25 MB** — GitHub rejects files over 100 MB and large videos bloat the repo permanently. Trim or compress first if needed. |
| `brand/` | Dealership logo, TVS dealer brand-pack files if you have them | PNG or SVG, largest available. Colour codes or layout PDFs are welcome too. |

The `.gitkeep` files only exist so the empty folders show up on GitHub — ignore them.
